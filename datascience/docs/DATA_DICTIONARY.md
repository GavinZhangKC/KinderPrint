# KinderPrint Data Dictionary

Generated from the processed tables. Regenerated by `scripts/build_dictionary.py`.

**Analysis unit:** AEDC reporting area (usually one SA2, sometimes 2-4 dissolved).
**Geography:** SA2, ASGS Edition 3 (2021). **Scope:** Greater Melbourne.

## Quality flags

| Flag | Meaning | Value populated? |
|---|---|---|
| `VALUE` | Usable measurement | Yes |
| `SUPPRESSED_LE3` | AEDC: three or fewer children assessed | No |
| `SUPPRESSED_RULE` | AEDC: <15 valid scores, or <2 teachers, or <80% coverage | No |
| `BOUNDED` | Published as a bound (e.g. `<=2`); no point estimate | No |
| `EXCLUDED_BY_PUBLISHER` | ABS excluded the area from SEIFA (low population) | No |
| `MISSING` | Absent from source | No |

No flag means imputed. Nothing in this dataset is imputed.

## Derived analytical fields

| Field | Meaning |
|---|---|
| `v0_count` | Priority V0: count of indicators past the 75th percentile. **Rejected** - correlated 0.795 with disadvantage |
| `v1_z` | Priority V1: standardised residual from the child-count-weighted model |
| `v1_band` | `Lower` / `Moderate` / `Higher`. Higher pre-registered at z >= 1.28 (ADR-004) |
| `match_idx` | Row index of the matched peer; -1 means no suitable match |
| `match_dist` | Mahalanobis distance to the peer |
| `match_strength` | `Strong` / `Moderate` / `Weak` from distance terciles |
| `sig` | Whether the matched-pair AEDC difference is significant at 95% |
| `ci_lo` / `ci_hi` | Wilson 95% interval on this community's vulnerability |

## Leakage rules (enforced in `tests/test_analytics.py`)

1. Environmental features are never matching features - matching on them would remove the differences under investigation.
2. AEDC outcomes are never matching features.
3. IRSD and raw Census income/education/employment never enter the same distance metric or composite.
