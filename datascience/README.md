# KinderPrint — Data Science

Pipeline and analytics for KinderPrint Iteration 1. Greater Melbourne, SA2, ASGS Edition 3 (2021).

## Run

```bash
pip install -r requirements.txt
python -m pytest tests/ -q          # 55 tests, runs on a fresh clone
```

The tests run immediately because the derived tables in `data/processed/` and the
reference geography in `data/reference/` are committed.

To rebuild everything from source, point the pipeline at your local raw data
(not committed - see the note below) and run:

```bash
export KINDERPRINT_RAW_DIR=/path/to/data/raw
python -m scripts.refresh_data
```

Expected raw layout:

```
data/raw/
  aedc/<date>/sa2-2009-24.xlsx
  seifa/<date>/Statistical_Area_Level_2__Indexes__SEIFA_2021.xlsx
  census/<date>/.../2021Census_G01_VIC_SA2.csv
```

Raw sources are deliberately not in git: they are large, immutable and freely
re-downloadable. Their SHA-256 checksums travel instead, in
`config/data_source_register.csv` and `outputs/iteration_1/run_manifest.json`,
so any published figure can be traced to the exact bytes that produced it.

**Running this on another machine:** see `docs/DATA_ACCESS.md` for download links,
the expected directory layout and checksums to verify against. `cp .env.example .env`
gives you a starting point for the path variable.

A full run takes about 41 seconds.

`refresh_data` writes `run_manifest.json` with input checksums, per-stage timings and
metrics. If the test suite fails, artefacts are not published.

Rejected after assessment: BoM AGCD (CC-BY-NC), Heat Vulnerability Index (built from

## Key decisions

**Geography.** SA2, ASGS **Edition 3 (2021)**. Edition 4 became the ABS default in July
2026 and its codes partially match Edition 3, so a naive join fails silently. Pinned.

**Analysis unit.** AEDC reporting area — usually one SA2, but 13 of 346 are groups of
2–4 SA2s AEDC merges to meet its minimum child count. `community_sa2` bridges them.

**No imputation.** Suppressed AEDC values stay suppressed. 4 communities excluded, 0 filled.

**Priority is a band, never a score.** Threshold pre-registered in ADR-004.

**Tree canopy, not total vegetation.** Canopy correlates −0.72 with urban heat, total
vegetation only −0.38, grass +0.13. ADR-005.

**Leakage rules.** Environmental and outcome variables never enter the matching metric.
